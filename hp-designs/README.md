# HP デザイン案（実装イメージ）

お試し環境の開発用メニュー（`/dev-menu`）の「HP デザイン案」に並ぶ見本ページの置き場所（Task 11-38）。
デザイナーのデザインを元に「実際に作るとこうなる」ページを案ごとに置く。

- `<案名>/index.html`（＋ 同じフォルダの CSS・画像）… ボタンを押すとこのページが開く。
  `index.html` が無ければ、フォルダ内の最初の HTML / PDF / 画像を開く。
- `<案名>.url` … 1 行目に URL（Canva・Figma など）を書くと、そのリンクを新しいタブで開く。
- 案名がそのままボタンの名前になる（例：`A案/` → 「A案 を見る」）。名前順に並ぶ。

ページは Laravel 経由で配信され、お試し環境の Basic 認証の内側にある（検索除けあり）。
本番（production）では開発用メニューごと無効なので表示されない。
