## デザインの考え方

「整える。その先の、動ける毎日へ。」
身体の不調が気になる方、運動を始めるのに不安がある方へ、治療と運動を組み合わせる価値を伝えます。大きな横長写真、明朝の見出し、墨色・石色・控えめな青、余白と細い罫線を使った編集的な構成です。既存案のグラデーション、丸いカード、左右分割ヒーローと異なる方向性です。

全ページ上部の「この案の考え方・改善点」から、制作意図と11項目の改善点を展開できます。この説明欄とサンプル表示は本番移行時に取り除く前提です。
