# 予約リソース：メニュー×ブース・スタッフの施術可否・資格（Task 11-28）

## 予約できる条件

次がすべて同時に成り立つ時間だけ予約できる。スタッフだけ、ブースだけが空いていても予約できない。

1. 担当スタッフがそのメニューの施術可能スタッフ（既存 `service_staff`）である。
2. メニューが必要とする資格（`qualification_service`）を、スタッフが全部保有している（`qualification_staff`）。
3. スタッフが勤務枠内で、予約・予定ブロックと重ならない（終了後バッファを含む）。
4. メニューに具体的なブースが紐付いている（`booth_service`）場合は、その中の少なくとも1つが、同じ時間（終了後バッファを含む）に空いている。1つ目のブースが埋まっていても、別の紐付けブースが空いていれば予約できる。

ブースの紐付けが1件も無いメニューは従来どおりで、全有効ブースから任意で選ぶ（未指定でも可）。

## 具体ブースの確定

- 予約は「ブースの種類」ではなく具体的なブース（`reservations.booth_id`）で確定し、`reservation_resource_slots` の一意制約で同じ時間の二重予約を防ぐ。
- 予約パネルは空いているブースを自動で提案し、別の空きブースへ変更できる（「自動（空いているブース）」＝未選択のまま予約すると、サーバーが紐付けブースのうち空いている最初の1つを確定する）。オンライン予約も同じ規則で自動確定する。
- 紐付けのあるメニューで、紐付いていないブースを指定すると `booth_id` の422。空きが無ければ「ブースが空いていません」。
- 予約の時間変更は、予約が確保している分数（延長を含む）と終了後バッファを保ったまま移動する。以前は標準所要時間で `ends_at` を作り直していたため、変更するとバッファが消えていた。

判定は `App\Domain\Reservation\BookingResourceResolver` の1か所に集め、空き枠計算（`AvailabilityService`）・予約作成/変更（`ReservationService`）・予約パネルの選択肢（`ReservationFormOptionsQuery`）が同じ規則を使う。

## 夫婦同時予約（受け入れケース）

パーソナル（トレーニングA・Bを紐付け、スタッフA・Bが施術可能）で14:00〜15:00：

| ケース | 条件 | 結果 |
|---|---|---|
| A | 夫：スタッフA、妻：スタッフB | 両方予約できる（夫＝トレーニングA、妻＝トレーニングB に自動確定） |
| B | トレーニングBも別予約で使用中 | 2件目は不可（スタッフBが空いていても） |
| C | トレーニングBは空き、スタッフBが勤務外 | 不可 |
| D | スタッフBがそのメニューの施術可能スタッフでない | 不可 |
| E | はりに「はり師」を必要資格として設定し、資格の無いスタッフで予約 | 不可（候補にも出ない） |

1予約に複数顧客を入れるグループ予約は今回扱わない（同時間帯の独立した2予約を正しく取れることを優先）。

## 設定画面と権限

| 設定 | 画面 | 権限 | 監査 |
|---|---|---|---|
| メニューで使えるブース | メニュー編集「利用できるブース」 | `services.manage` | `service.booths_set` |
| メニューに必要な資格 | メニュー編集「必要な資格」 | `services.manage` | `service.qualifications_set` |
| スタッフが実施できる施術（`service_staff` をスタッフ側から） | スタッフ編集「実施できる施術」 | `staff.manage`（パスワード再確認） | `staff.services_set` |
| スタッフの保有資格 | スタッフ編集「保有資格」 | `staff.manage`（パスワード再確認） | `staff.qualifications_set` |
| 資格マスタ | 業務マスタ「資格」タブ | `settings.manage` | `karte_master.*` |

資格名をコードにハードコードしない。マスタには選択肢として「はり師」だけを用意し、誰が保有するか・どのメニューに必要かは推測で埋めない（画面で設定する）。一般スタッフ（staff ロール）はいずれも変更できない。

## 既知の制約

- 紐付けを設定するまでは、既存メニューは従来どおり全ブースが候補（紐付けを推測で作らない）。
- 予定ブロック（休憩・清掃）はブース単位・スタッフ単位で従来どおり判定する。
