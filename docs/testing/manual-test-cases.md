# ARK 動作確認テストケース一覧

ARK のすべての機能を、実際の画面で確認するためのテストケース一覧です。機能ごとに分けています。

- 実施結果の最新は `docs/testing/2026-09-27-full-verification.md` を参照。
- 「備考」の **確認済** は 2026-09-27 の全面検証でブラウザ確認済み、**自動** は自動テストで確認済み、**BLOCKED** はまだ確認できないもの、**未実装** は機能が無いものです。
- 環境はローカル（`http://localhost`、Sail）。本番DB・Stripe Live・外部予約APIには接続しない。
