# Phase 11 / Task 11-11 6シートExcel出力

## 利用可能範囲と提供原本

2026-09-25に提供された`ARK自由が丘店2026.10.xlsx`を読取専用で解析した。SHA-256は`739c6dd1655ced0e4f7c47c3cb7e595a2f52d78ba3a8480fe55d2f438268c9d6`。同一hashの複製を`resources/report_templates/ark-jiyugaoka-2026-10-source.xlsx`に配置し、`WorkbookTemplateRegistry`がhash検証後にメモリへ読み込む。元のDownloadsファイルは変更しない。元ファイル名の「が」は分解形U+304B U+3099であり、ダウンロード名もこれに合わせて`ARK自由が丘店YYYY.MM.xlsx`とした。原本の第6シート名は仕様文書の全角括弧ではなく、半角括弧の`年間計画書 (実数)`である。コピー方式では原本の名称を維持する。

`GET /admin/reports/excel?year=YYYY&month=M&basis=payment_date&as_of_date=YYYY-MM-DD`が管理者向けダウンロード。`reports.view`・`sales.view`・`reports.export`をすべて要求し、出力操作を監査する。原本コピー利用時のファイル名は`ARK自由が丘店YYYY.MM.xlsx`。画面には権限保持者だけリンクを出す。原本互換帳票は既存運用どおり決済日基準のみとし、施術日基準選択中は出力リンクを非表示にして理由を表示、直接`basis=treatment_date`を指定したAPIも422で拒否する。施術日基準はARKの管理画面/APIから取得する。

出力値は`MonthlyReportService`、`CustomerAnalyticsService`、`StaffUtilizationService`、`AnnualReportService`のread modelが正本。基準日翌日以降の日別実績セルはNULL/空欄にする。年間の将来月も実績は空欄、売上目標のみ表示できる。0、NULL、未判定を混同しない。原本の数式には税率1.1/1.08の固定割算、分母0を0%とする`IFERROR`、旧定義の計算、未対応の`__xludf.DUMMYFUNCTION`があるため、**出力コピーの数式は一旦全て除去し、ARK値を対応セルへ書く**。原本の書式・結合・行高・列幅は保持する。原本の静的な経費予算は残すが、ARKの実績と誤認しない。文字列は明示的なExcel文字列型にし、式開始文字を無害化する。

## テンプレート保護

`config/report_export.php`は提供原本コピーのbasenameとSHA-256を既定設定する。NULLにすれば旧暫定レイアウトへ戻せる。`WorkbookTemplateRegistry`はパス逸脱、hash不一致、実原本の6シート名/順番不一致を拒否し、元ファイルはメモリへ読み込むのみで書き込まない。別版の原本ではmappingを見直すこと。出力名は原本の店名/年月形式に合わせるが、基準日はファイル名に含まれないためダウンロード時の対象基準日はAPIリクエストと監査ログで追跡する。

Google Sheets実書込、SALON BOARD、外部予約サイト同期、帳票メール自動送信は対象外。
